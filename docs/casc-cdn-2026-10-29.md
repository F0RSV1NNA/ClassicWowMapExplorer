# CASC lookup, CDN fallback and BLTE decoding — 2026-10-29

The owner's `transport-inventory.json` records ten ready roots, 85 `unknown` roots and 48 group/LOD entries for `wow_classic_beta` build `1.60.1.70532`.

`unknown` meant absent from Explorer's **filtered** root index, not proof the file was absent from the game's raw root table. Explorer discarded every alternate (0x80) record. CASCLib, as used by Mappster, retains alternate-only files and prefers ordinary records when both exist. Explorer now follows that rule. This corrects the earlier explanation that every unknown entry was necessarily missing from the selected build.

Additional Mappster capabilities implemented:

- Local lookup searches every encoding and tries a readable alternate if the preferred encoding has an unavailable decryption key.
- Missing local payloads fall back to the selected build's CDN identity. The reader tries the loose encoded file, then the selected CDN config's archive-group or individual archive indexes and exact byte ranges.
- CDN downloads are cached in the browser's content cache. Encoded BLTE headers/payloads are checked against their requested encoding hash, and ranged responses must match the requested range and length.
- BLTE Salsa20/20 decoding uses the key catalog already present in the owner-provided CASCLib checkout. No unknown-key recovery is attempted. Unknown keys remain explicit errors for complete file reads; the existing opt-in partial DB2 reader still reports its missing keys.
- Dev and portable servers provide an HTTPS CDN bridge for browsers where the remote server does not expose CORS headers. The bridge forwards no cookies and accepts only the content/metadata host families. The portable launcher now includes that bridge, so replacing only the web assets is insufficient.

No other product's files are silently substituted. A truly missing file identity or unknown key remains in the inventory report. The final number of models in the owner's running Forever session requires a fresh load; fixture success does not establish that all 95 candidates exist and are readable in that session.
